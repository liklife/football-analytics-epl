\# Football Analytics: EPL 2025/26



\## О проекте



Учебный проект по анализу футбольных данных Английской Премьер-лиги за сезон 2025/26.



Цель проекта — изучить связь между количеством ударов, ударами в створ и забитыми голами, а также сравнить эффективность команд.



\## Аналитические вопросы



\- Какие команды забили больше всего голов?

\- Как различается конверсия ударов в голы?

\- Всегда ли большое количество ударов связано с большим количеством голов?

\- Какие команды эффективнее используют свои голевые возможности по выбранным показателям?



\## Инструменты



\- PostgreSQL — хранение данных и SQL-анализ.

\- Python — выполнение аналитического скрипта.

\- pandas — обработка данных и расчёт показателей.

\- SQLAlchemy и psycopg — подключение Python к PostgreSQL.

\- Matplotlib — визуализация.



## Результаты

В проекте рассчитаны сезонные показатели всех 20 команд Английской Премьер-лиги за сезон 2025/26.

Рассчитанные показатели:
- количество забитых голов;
- общее количество ударов;
- количество ударов в створ;
- конверсия ударов в голы;
- доля ударов в створ от общего количества ударов;
- отношение забитых голов к ударам в створ.

Результаты сохранены в CSV-файл `results/team_analysis.csv`. Для визуального анализа построены графики `results/shot_conversion.png` и `results/shots_vs_goals.png`.

## Статус

Основной аналитический скрипт реализован и проверен на локальной базе PostgreSQL. Подготовлены SQL-запросы и графики.

В работе остаются инструкции по воспроизведению проекта, финальные выводы и публикация на GitHub.
## Источник данных

Для проекта использованы результаты матчей и базовая статистика Английской Премьер-лиги сезона 2025/26 с сайта [Football-Data.co.uk](https://www.football-data.co.uk/englandm.php).

Набор данных включает даты матчей, названия команд, забитые голы, общее количество ударов и ударов в створ ворот.

Исходный CSV-файл хранится локально и используется для анализа. Перед публикацией исходных данных в открытом репозитории необходимо проверить актуальные условия их использования и распространения.

Результаты проекта носят описательный характер. Реализация ударов (отношение забитых голов к общему количеству ударов) не учитывает качество голевых моментов. Удары мимо ворот могут включать заблокированные удары, поэтому этот показатель не следует автоматически интерпретировать как количество чистых промахов.
