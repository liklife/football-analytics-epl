# Football Analytics: EPL 2025/26

## О проекте

Учебный проект по анализу статистики матчей Английской Премьер-лиги за сезон 2025/26 с использованием SQL и Python.

**Цель:** изучить связь между количеством ударов, ударами в створ и забитыми голами, а также сравнить результативность команд по выбранным показателям.

## Аналитические вопросы

- Какие команды забили больше всего голов?
- Как различается конверсия ударов в голы?
- Всегда ли большое количество ударов связано с большим количеством голов?
- Какие команды показывают более высокую результативность по отношению к количеству ударов?

## Инструменты

- **PostgreSQL** — хранение данных и SQL-анализ.
- **Python** — выполнение аналитического скрипта.
- **pandas** — обработка данных и расчёт показателей.
- **SQLAlchemy и psycopg** — подключение Python к PostgreSQL.
- **Matplotlib** — визуализация результатов.

## Результаты

В анализ включены 380 матчей и 20 команд.

Для каждой команды рассчитаны:

- количество забитых голов;
- общее количество ударов;
- количество ударов в створ;
- конверсия ударов в голы;
- доля ударов в створ от общего количества ударов;
- отношение забитых голов к ударам в створ.

Результаты сохранены в CSV-файле `results/team_analysis.csv`.

## Источник данных

[Football-Data.co.uk — статистика английских лиг](https://www.football-data.co.uk/englandm.php).

Использованы даты матчей, названия команд, количество забитых голов, общее количество ударов и ударов в створ ворот.

Исходный CSV-файл хранится локально и не включён в репозиторий. Перед распространением исходных или обработанных данных необходимо учитывать действующие условия их использования.

## Ограничения анализа

- Конверсия ударов не учитывает качество голевых моментов.
- Удары, не попавшие в створ, не обязательно являются чистыми промахами: в эту категорию могут входить заблокированные удары.
- Анализ описывает результаты одного сезона и сам по себе не доказывает причинно-следственные связи.

- `results/` — итоговая таблица и графики.
- `docs/` — дополнительные материалы проекта.
